# HTML1_Lexa

Proyecto web educativo en español para aprender la estructura de una página con HTML y CSS, y conocer los pasos básicos para publicarla en GitHub Pages. Incluye una vista previa interactiva de una página tributo a Lexa kom Trikru.

## Ver el proyecto

Abre `index.html` en un navegador. Para publicarlo, activa GitHub Pages desde **Settings > Pages** y selecciona la rama `main` con la carpeta `/(root)`.

## Estructura

```text
HTML1_Lexa/
|-- index.html
|-- CSS/
|   `-- style.css
`-- img/
    |-- images.jpeg
    |-- lexa.jpeg
    `-- lexa3.jpg
```

## Tecnologías

- HTML5 y CSS3
- Tailwind CSS mediante CDN
- JavaScript para navegación, vista previa y descarga de imágenes
