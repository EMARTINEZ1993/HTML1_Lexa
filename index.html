Introducción a HTML y CSS

Conoce las herramientas que dan estructura y estilo a este proyecto antes de explorar su código.

¿Qué es HTML?

HTML es el lenguaje de marcado que organiza el contenido de una página. Sus etiquetas indican qué función cumple cada elemento, como un título, un párrafo, una imagen o una sección.

Etiquetas utilizadas en este proyecto

Etiqueta Uso
<header>Cabecera
<main>Contenido principal
<section>Sección temática
<footer>Pie de página
<h1>–<h2>Títulos
<p>Párrafo
<img>Imagen
<ul> / <li>Lista
<strong>Énfasis importante
<em>Énfasis
<div>Contenedor
<link>Hoja de estilos

Atributos HTML del proyecto

class asigna estilos; id identifica un elemento; src indica la ruta de una imagen; alt describe la imagen; href indica la ruta de un recurso; onclick ejecuta una acción; target y rel configuran enlaces. lang, charset, name y content aportan información del documento.

¿Qué es CSS?

CSS es el lenguaje que define la apariencia de los elementos HTML: colores, tamaños, espacios y distribución. En este proyecto, los estilos de la página tributo están organizados en CSS/style.css.

Propiedades CSS utilizadas

Propiedad Uso
colorColor del texto
background-colorFondo
font-familyTipografía
font-sizeTamaño del texto
text-alignAlineación
marginEspacio exterior
paddingEspacio interior
max-widthAncho máximo
displayTipo de distribución
gapEspacio entre elementos
height / widthDimensiones
object-fitAjuste de imágenes

¿Cómo trabajan juntos?

HTML crea la estructura y CSS la presenta. Por ejemplo, la etiqueta <header> define la cabecera, mientras que una regla CSS puede darle un fondo oscuro, texto centrado y espacio interior.

Paso a Paso: Subir Repositorio a GitHub

Sigue este flujo secuencial en la terminal de Visual Studio Code para subir tus archivos a GitHub.

¡Visita mi perfil y sígueme en GitHub! github.com/EMARTINEZ1993
1

Crear el repositorio en la web de GitHub

  1. Ingresa a tu cuenta de GitHub.com.
  2. Haz clic en el botón verde "New" o en el símbolo "+" arriba a la derecha.
  3. Nombra el repositorio (ejemplo: lexa-tributo o mi-proyecto).
  4. Déjalo en modo Public (público) para que GitHub Pages sea gratuito.
  5. IMPORTANTE: No marques las casillas de agregar README, .gitignore o licencia por ahora.
  6. Haz clic en "Create repository".
2

Abrir la Terminal en Visual Studio Code

En VS Code, abre la carpeta donde tienes guardado tu proyecto y abre la terminal usando el menú superior Terminal -> New Terminal o con el atajo Ctrl + ~.

3

Ejecutar la secuencia de comandos Git

Ejecuta uno a uno los siguientes comandos en tu terminal:

# 1. Inicializar repositorio Git local
git init
# 2. Agregar todos los archivos al área de preparación
git add .
# 3. Guardar cambios con mensaje inicial
git commit -m "Initial commit"
# 4. Cambiar rama principal a 'main'
git branch -M main
# 5. Copiar la URL dada por GitHub y vincular (Reemplaza la URL)
git remote add origin https://github.com/TU-USUARIO/TU-REPOSITORIO.git
# 6. Subir tu código a GitHub
git push -u origin main

Desplegar la Página con GitHub Pages

Activa el alojamiento gratuito de GitHub para que cualquier persona pueda visitar tu página web en internet.

1 Aceder a Settings

Dentro de tu repositorio en GitHub, dirígete a la barra superior del menú y haz clic en la pestaña con ícono de engranaje "Settings" (Configuración).

2 Ir a la sección Pages

En el menú lateral izquierdo, busca la sección **"Code and automation"** y selecciona la opción "Pages".

3 Configurar la Rama (Branch)

En el apartado "Build and deployment" -> "Branch":

  • Cambia el selector de None a main.
  • Asegúrate de que la carpeta esté en /(root).
  • Presiona el botón "Save" (Guardar).
4 Obtener el Enlace Publicado

Espera de 1 a 3 minutos. Recarga la página y verás un cuadro verde en la parte superior con la URL final de tu sitio web publicado.
